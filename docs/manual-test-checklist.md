# 真機與連線測試清單

自動測試只能用電腦對打和模擬按鍵，以下這些要用真的手機、真的兩台裝置試過才算數。
每一項試完在 `[ ]` 裡打 `x`；有問題的話記下「裝置 / 瀏覽器 / 發生什麼事」。

網址：https://jamesleecy.github.io/brawl-kids/（測試前先重新整理，確認是最新版）

## 1. 手機單機（每支手機都試一次）

裝置：＿＿＿＿＿＿　瀏覽器：＿＿＿＿＿＿

- [ ] 標題畫面：角色、按鈕都完整顯示，沒有被切掉
- [ ] 選角：游標預設停在「?」隨機；點頭像可以換角色
- [ ] 選「隨機」開打，抽到的角色正常出現
- [ ] 搖桿（按住螢幕左半邊拖曳）走路、快推兩下跑步都順
- [ ] 「必殺」「必殺跳」放得出 6 招（推搖桿↑ / ↓ / 不推）
- [ ] 菜阿嘎「好吃好吃」（↑ + 必殺跳）：按住「必殺跳」不放，血有越補越多
- [ ] 揪門「大胃王蓄力」（↓ + 必殺）：按住「必殺」，放開時震地
- [ ] 大招切入畫面（例如講萬安 ↓ + 必殺跳「颱風假」）出現時不會卡頓
- [ ] 打完一場不會突然變卡；若變卡，畫面上方是否出現「畫面較慢，已自動切換為低畫質」
- [ ] 設定 → 畫面晃動：「關」之後震地招完全不晃
- [ ] 暫停 → 招式表：可以左右翻頁，最後一頁是狀態說明，字看得清楚
- [ ] 新手教學最後一步「特殊狀態」看得到說明，點攻擊可以完成
- [ ] 手機轉橫向 / 直向，畫面不會跑版
- [ ] 加到主畫面（PWA）後從圖示打開可以玩

## 2. 連線對戰（兩台裝置，最好一台手機一台電腦）

房主裝置：＿＿＿＿＿＿　加入者裝置：＿＿＿＿＿＿

- [ ] 房主建立房間，加入者用分享連結進得來
- [ ] 雙方都選「隨機」：開打後兩邊看到的角色一樣
- [ ] 打一場到分出勝負，中間沒有出現「不同步」警告
- [ ] 豪豪「叛徒啦叛徒」（2 對 2 時）：被策反的人兩邊看到的都在打自己隊友
- [ ] 川噗「築一道高牆」：兩邊的牆位置一樣，都過不去
- [ ] 揪門「開箱翻車」（隨機結果）：兩邊開出的東西一樣
- [ ] 「再來一場」：選隨機的人重新抽，兩邊一致
- [ ] 一方關掉分頁：另一方有提示，不會卡死

## 3. 其他

- [ ] 結算畫面兩人同時勝利（例如組隊 2 對 2），口頭禪沒有疊在一起
- [ ] 觀看重播：播到最後沒有「重播與原比賽不一致」
- [ ] 分享重播連結，另一台裝置打得開

## 回報格式

```
項目：例如「2. 雙方都選隨機」
裝置：iPhone 13 / Safari
發生什麼事：房主是川噗，加入者那邊顯示成金正嗯
```
