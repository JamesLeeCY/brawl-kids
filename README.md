# 台灣大亂鬥 Taiwan Brawl

瀏覽器上的 2.5D 亂鬥格鬥遊戲：最多 2 名玩家共用一副鍵盤，再加上最多 2 名電腦，在台北街頭互毆、丟道具、放必殺技。所有美術、音效與背景音樂都以程式即時繪製 / 合成，沒有任何圖檔或音檔。

> 20 名角色皆為諧音梗命名的 Q 版戲仿造型（台灣政治人物、網紅與世界領袖靈感，僅以髮型、眼鏡、服裝、配件與代表色呈現），純屬虛構娛樂，與任何真實人物無關，也不代表任何政治立場。

## 快速開始

在 Windows PowerShell 中（PowerShell 5.1 不支援 `&&`，請分兩行或用 `;`）：

```bash
cd D:\side_project\LF2_Game\brawl-kids
```

```bash
npm run dev
```

接著開啟 http://localhost:5173 。其他指令：`npm test`（自動測試）、`npm run build`（輸出 `dist/`，可直接部署到靜態主機）。

## 操作鍵位（兩人一副鍵盤，間隔加寬）

P1 坐左邊、P2 坐右邊。按鍵可在標題畫面「設定」重新綁定（存於 localStorage）。

| 玩家 | 上 / 下 / 左 / 右 | 攻擊 | 跳躍 | 防禦 |
| --- | --- | --- | --- | --- |
| P1 | W / S / A / D（左手） | J | K | L（右手） |
| P2 | ↑ / ↓ / ← / →（左手） | 數字鍵 1 | 數字鍵 2 | 數字鍵 3（右手） |

> 筆電沒有數字鍵盤時，請到「設定」把 P2 的攻擊 / 跳躍 / 防禦改成例如 `,` `.` `/` 或 `[` `]` `\`。

其他按鍵：`Esc` 回上一頁 / 戰鬥中暫停，`Enter` 在選單中等同攻擊，`F3` 顯示 FPS。

### 手機 / 平板觸控操作（荒野亂鬥式）

在手機或平板打開網址會自動出現觸控按鈕，按鈕直接疊在遊戲畫面上；**請橫向持握**，戰鬥畫面會加寬填滿整個螢幕（直向會提示轉橫向）。

- **浮動搖桿**：左半邊任意位置按下，搖桿就出現在手指下；拖太遠會跟著手指移動，放開即消失。快速往同方向推兩次 = 跑步
- **攻擊（大紅鈕）/ 跳躍 / 防禦**：同鍵盤的 J / K / L
- **必殺（黃鈕）/ 必殺跳（紫鈕）**：一鍵放出「防禦＋方向＋攻擊 / 跳躍」。推著搖桿按就是該方向的招式，沒推時朝面向放 D→A / D→J。外圈黃色是 MP 充能，越滿可以放越多次
- 手機上的招式說明會自動改用觸控寫法：「必殺」＝直接點必殺鈕、「↑必殺」＝搖桿往上推再點必殺、「↓必跳」＝搖桿往下推再點必殺跳。對照鍵盤：D→A＝必殺、D↑A＝↑必殺、D↓A＝↓必殺、D→J＝必跳、D↑J＝↑必跳、D↓J＝↓必跳
- **右上 Ⅱ**：暫停 / 選單；**⛶**：全螢幕（Android 會同時鎖定橫向，iPhone Safari 不支援全螢幕，可用「加入主畫面」獲得接近全螢幕的效果）
- 按鈕大小會依螢幕高度自動縮放；接上實體鍵盤按任一鍵會隱藏觸控按鈕
- 連線：朋友直接點分享連結就能加入；房主在手機上「複製連結」會改用系統分享選單；手動加入時點一下畫面即可輸入房間代碼

手機一次只能操作一名角色（1P），兩人同樂請各用一支手機開連線對戰。

### 基本動作

- **連擊**：攻擊 ×3（間隔 15 tick 內），第 3 段擊倒
- **跑步**：前方向鍵快速連按兩次（按住持續跑）
- **跑步中**：攻擊 = 衝撞、跳躍 = 衝刺跳、防禦 = 翻滾（無敵）
- **空中攻擊**：飛踢
- **防禦**：按住減傷 90%，防禦值歸零會破防硬直
- **道具**：靠近按攻擊撿起；持有時攻擊揮擊，跑步 / 跳躍中攻擊投出；木箱只能投擲
- **抓摔**：走向暈眩中的敵人自動抓住，攻擊 = 揍打、方向 + 攻擊 = 摔出

### 20 名角色與必殺技（每人 6 招，兩種按法都可以）

- **簡單按法**：按住「防禦＋方向」，再按攻擊或跳躍。例如 1P 按住 `L` + `D`，再按 `J` = D→A。
- **依序按法**：防禦 → 方向 → 攻擊/跳躍（30 tick ≈ 0.5 秒內，中間多按其他鍵也沒關係）。

「→」為前方：按左或右都算，角色會轉向那個方向。D↑A 用上、D↓A 用下；最後按跳躍則是 D→J / D↑J / D↓J。

### 背景音樂

全部用 Web Audio 即時合成（`src/audio/music.ts`，譜面在 `src/audio/tracks.ts`），沒有音檔。每個場地一首；標題與選單、闖關頭目波（頭目出場到被打倒）、勝利、失敗另有專屬曲子，勝利 / 失敗是只播一次的短曲。「設定」可調整音樂音量（與主音量、音效音量一起存在 localStorage）。瀏覽器規定要先有使用者操作才能出聲，所以第一次按鍵或點畫面後才開始播放；切到其他分頁時自動暫停。音樂只在本機播放、只讀取畫面狀態，不影響模擬，連線對戰不會因此不同步。

## 新手教學

標題畫面「新手教學」（第一次打開時會預先選好）：約 30 秒，依序教 移動 → 跳躍 → 攻擊 → 防禦 → 必殺技，做到了才會進下一步，提示會依鍵盤或觸控顯示對應的按法。完成後可以直接進練習模式。

## 成就與角色戰績

標題畫面「成就」：13 個成就（例如用全部角色各贏一場、闖關 10 關全破、困難全破、連線勝利、練習模式連段 300 傷害、放出同一角色全部 6 招），以及每個角色在這台裝置上的勝場 / 場數。新解鎖的成就會在結算畫面左上角或練習模式中顯示。資料只存在這台裝置的瀏覽器（localStorage）。

## 遊戲速度

「設定」→「遊戲速度」：快（原速）／中（預設，0.85 倍）／慢（0.7 倍，招式更好打中）。連線對戰以房主的設定為準，房主的連線選角畫面模式列會顯示目前速度。

## 畫質設定（舊手機）

「設定」→「畫質」：自動（預設）/ 高 / 低。低畫質用 1 倍解析度繪製、關掉光暈模糊、少畫殘影與震地粒子，手機上要畫的像素少約四分之三。設成自動時，戰鬥中若連續約 2 秒低於 48 FPS 會自動切換為低畫質，畫面上方會短暫提示。

## 練習模式

選模式畫面用 ← → 切到「練習模式」：選場地、沙包行為（站著不動 / 電腦簡單・普通・困難）與沙包角色（守衛機器人或任一角色）。

- 真人玩家無限 MP、不會倒下；沙包 HP 無限，2 秒沒被打就回滿。
- 畫面左上（2P 在右上）列出自己的 6 招與按法，放出來就打勾，並顯示剛放出的招式名稱。
- 下方顯示連段次數與傷害、最高連段傷害。Esc 選單可重新開始或回選角。

## 比賽重播

每場本機或連線比賽都會自動錄下來（只存開場設定與每個 tick 的真人按鍵，模擬是決定論的，所以能一模一樣重現）。結算畫面右上：

- **觀看重播**（跳躍鍵或點按鈕）：攻擊 / 空白鍵暫停、跳躍切換 1× / 2×、← → 前後跳 5 秒，也可以直接點下方進度列跳到任何時間點，防禦 / Esc 離開。
- **分享重播**（↑ 或點按鈕）：複製一個 `#replay=…` 連結（手機會開分享選單），朋友打開就直接看重播。一般兩分鐘的比賽連結約 2～6 KB；萬一超過約 8 KB，改為複製重播代碼文字，在標題畫面按 Ctrl+V 貼上即可觀看。
- 連線時看重播仍會收到房主的「再來一場 / 回選角」。闖關模式只錄目前這一關；練習模式不錄。
- 重播綁定遊戲版本：網站更新後，舊的重播連結會顯示「另一個版本的遊戲錄的」，不會播放跑掉的畫面。

## 安裝到手機主畫面（PWA）

網站可以像 App 一樣安裝：Android Chrome 選單「加入主畫面 / 安裝應用程式」，iPhone Safari 分享選單「加入主畫面」。從主畫面開啟會全螢幕橫向，第二次開啟更快（遊戲檔案已快取）。網站更新時仍會自動換成新版。

## 闖關模式（1～10 關、三種難度，場景可選原本路線、隨機或自選）

選模式畫面選「闖關模式」後，上排三個設定用 ← → 切換：難度、關卡數（1～10，預設 4）、場景（原本路線 / 隨機 / 自選）。下方的 Q 版場地卡片就是這次的路線，自選時用 ↑↓ 選卡片、←→ 換場景。

| 難度 | 敵人 AI | 每波敵人 | 敵人血量 | 頭目血量 |
| --- | --- | --- | --- | --- |
| 簡單 | 降一級 | 標準 | 80% | ×1.1 |
| 普通 | 標準 | 標準 | 100% | ×1.3 |
| 困難 | 升一級 | 每種多 1 隻 | 130% | ×1.8 |

`stages.json` 的 `campaign` 有 10 個由易到難的關卡模板（第 5 關起會混入其他角色當精英敵人，第 10 個有頭目）。選較少關數時會平均取樣，最後一關一定是頭目關；預設 4 關 = 台灣大學 → 西門町 → 東區大巨蛋 → 信義區，和以前一樣。超過 4 關時每關之間回復的 HP 較多。數值在 `campaignDifficulty` 可調整。

## 連線對戰（最多 4 人，各自一台電腦）

標題畫面選「連線對戰」：

1. **房主**選「建立房間」，直接進入連線選角，畫面上方有 6 碼房間代碼與分享連結（房主確定後按攻擊可複製連結）。
2. **朋友**打開連結就會自動加入（最多 3 位，依序成為 2P / 3P / 4P）；或選「加入房間」手動輸入代碼。
3. 畫面上方是所有角色的頭像格（15 名排成 5×3），每人各自用方向鍵在格子上移動自己顏色的游標選角（手機也可直接點頭像），跳躍換隊伍（合作闖關不分隊，房主按跳躍改為設定闖關場景），攻擊確定。房主在頭像格最下列再按 ↓ 會移到「模式」按鈕，←→ 切換對戰（各場地）或合作闖關（簡單 / 普通 / 困難）；房主確定後按 ← / → 可把空位設為電腦。
4. 所有玩家都確定後自動開始。結算後由房主按攻擊「再來一場」或按防禦帶大家回到連線選角。
5. 比賽中有人斷線，其他人會繼續玩（畫面下方顯示「XP 已離線」）；房主離線則比賽結束。

連線時你可以用 WASD + J/K/L 或 方向鍵 + 數字鍵 1/2/3 任一組操作。遊戲中按 Esc 會開選單，但**連線時遊戲不會暫停**。

**運作方式**：使用 WebRTC 點對點（PeerJS），房主是中心，每位朋友只連房主，房主轉送大家的按鍵，不需要自架遊戲伺服器。PeerJS 的免費配對伺服器只負責「介紹」玩家，遊戲資料直接在電腦之間傳送。遊戲是決定論 lockstep：大家只交換按鍵，各自計算同一個世界；輸入延遲依最慢玩家的網路延遲自動調整（直連 3–14 tick），因此畫面順暢度取決於網路最慢的那位。

**中繼備援**：若 6 秒內無法直連（雙方都在嚴格的 NAT / 公司 / 學校網路後面），會自動改用公用 MQTT 伺服器（EMQX、HiveMQ）轉送按鍵，畫面上方顯示「中繼」。中繼可以正常對戰，但延遲較高，按鍵會感覺慢半拍（輸入延遲最多 30 tick）。經過公用伺服器的只有房間代碼與按鍵資料，其中 broker-cn.emqx.io 位於中國大陸。

**注意事項**：

- 大家都要開同一個網址、同一版本；版本不同會提示「請重新整理」（手機請關掉分頁重開）。網站更新後，開啟時也會自動偵測並重新整理一次。
- 房主在手機上切到 LINE 等 App 分享連結後回來，房間代碼與連結仍然有效。
- 若一直連不上，會在 25 秒內顯示原因；直連失敗時會自動改走中繼，若中繼也失敗，多半是網路擋住了 WebSocket，換手機熱點通常就能解決。
- 加入時最多會自動等房主 60 秒；房主分享連結後請回到遊戲畫面。連不上時，加入畫面下方會顯示每一步的狀態（配對伺服器、直連、中繼伺服器、房主在線、房主回應），打勾表示成功、✗ 表示失敗，回報問題時請一併提供。
- 想測試中繼，可在分享連結後加上 `&relay=1`（例如 `?room=ABC123&relay=1`），會跳過直連直接走中繼。
- 網路不穩（手機切換 Wi-Fi / 4G、螢幕暫時關掉、切到 LINE 再回來）會自動重新連線並接著比賽：斷線的人看到「正在重新連線…」，其他人看到「等待重新連線…」。比賽中超過約 30 秒沒回來才會視為離線，其他人繼續打。
- 切換到其他分頁會讓瀏覽器暫停遊戲，對手會看到「等待對手…」。
- 畫面左下顯示延遲（ms）；若出現「⚠ 畫面可能不同步」請回選角重開一局。

選角畫面：上方是所有可選角色的頭像格（15 名排成 5×3，左右 / 上下循環），每位玩家的游標用欄位顏色標示（1P 紅、2P 藍、3P 綠、4P 黃）。1P、2P 按自己的攻擊鍵加入，方向鍵在頭像格選角、跳躍換隊伍、攻擊確定、防禦退出；3、4 號欄位只能放電腦。手機上用搖桿移動游標，也可以直接點頭像。

**設定電腦對手**：

- 1P 一個人確定角色後，會**自動進入「設定電腦」**，游標在 2P 欄位：攻擊在「加入（簡單）→ 普通 → 困難 → 移除」間切換；加入後用方向鍵在頭像格移動電腦的游標（標「COM」）選角，跳躍換隊伍，**防禦＝換下一個欄位**。空欄位上 ←→ 換欄位、**防禦＝完成**（不加電腦直接按防禦就是單人開始，例如單人闖關）；最後一個欄位按防禦也是完成。
- 已有其他玩家或電腦時，全員確定後 1.5 秒自動進入下一頁；倒數中 1P 按 ← / → 可再進入「設定電腦」（倒數暫停），按攻擊可立即開始。
- 手機上同樣操作：搖桿左右 / 上下，點「攻擊」「跳躍」「防禦」按鈕。

## 如何新增角色

1. 在 `src/data/characters/` 新增一個 JSON 檔（可複製 `jiang.json` 修改），**不需要改任何程式碼**，重新整理即出現在選角畫面。
2. 必填欄位：`id`（小寫英數與底線）、`name`、`stats`（hp / walkSpeed / runSpeed / jumpPower / weight）、`palette`（skin / main / accent，`#RRGGBB`）。
3. 基本動作（連擊、跑攻、飛踢、揮擊、投擲）來自 `src/data/base_frames.json`；角色 `frames` 中的同名幀會覆寫它們（見 `guardbot.json`）。
4. 必殺技：在 `moves` 加入最多 4 招，`command` 為 `D>A`、`D^A`、`DvA`、`D>J`、`D^J`、`DvJ`，`startFrame` 指向 `frames` 中的幀。
5. 幀欄位：`duration`（tick）、`pose`（`src/render/poses.ts` 的姿勢名）、`next`（下一幀，`"idle"` 回到站立）、`itr` 攻擊框、`bdy` 受擊框、`spawn` 產生飛行物、`selfVel` 自身速度、`buff` 增益（`dmgReduce` / `blockProjectile` / `hover`）、`onA` 連擊接續、`heal` 回復 HP、`sound` 音效。
6. 飛行物定義在角色的 `projectiles` 中，本身也是帶 `frames` 的實體；`onHit` / `onExpire` 可接續另一個飛行物（例如爆炸），`homing` 追蹤、`pull` 吸引敵人。
7. `accessory` 決定辨識配件（`pin`、`bear`、`stethoscope`、`headmirror`、`robot`；其他值則不畫配件）；`look` 設定髮型（`short` / `sidepart` / `neat` / `receding` / `none`）、`glasses`、`tie` 領帶色。`selectable: false` 可讓角色只當闖關雜兵。

載入時以 zod 驗證，格式錯誤會在瀏覽器主控台列出檔名與欄位，並略過該角色。`npm test` 也會檢查所有 `next` / `startFrame` 參照。

新增場地同理：在 `src/data/stages.json` 的 `stages` 加一筆；`theme` 不認得時使用通用背景（依 `palette` 上色）。

## 專案結構

```
src/
  config.ts        全域數值（物理、戰鬥、AI、道具）
  sim/             純邏輯（無 DOM）：world、fsm、combat、commands、ai、items、projectiles、rng
  input/           鍵盤 → 每 tick 按鍵快照
  render/          Canvas 繪圖：姿勢、角色、場地、特效、HUD
  audio/           Web Audio 合成音效與背景音樂（譜面、排程、依場景選曲）
  scenes/          標題、設定、選角、選模式、戰鬥、結算、重播
  replay/          重播錄製、編碼（run-length + deflate + base64url）與分享連結
  data/            角色 / 道具 / 場地 JSON 與 schema
tests/             Vitest：決定論、指令、戰鬥、資料、AI、闖關、重播
```
